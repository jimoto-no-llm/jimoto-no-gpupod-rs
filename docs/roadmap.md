## P1 マーケットプレイス設計（案）

### 価格

**価格は扱わない**（全提供者・全 GPU が無料）。検索と並び替えは空き状況・VRAM・ベンダーだけで行う。

- 画面では「無料」と明示する。

### 検索 API

```
GET /api/offers?vendor=nvidia&model=4090&min_vram_mib=24576&available=1&sort=vram
```

返す項目は公開情報のみ: GPU 名・ベンダー・VRAM・提供者表示名・空き状態・最終更新。
**IP・ノード ID・内部パスは返さない。**

### 画面

- `/` の「借りられる GPU」を検索 UI に拡張（今は一覧のみ）。
- 絞り込み: ベンダー、VRAM 下限、空きのみ。
- 並び替え: VRAM / 新着 / 提供者の稼働率。
- カードから借りる画面へ（SSH 鍵・テンプレート・予約量を選択）。

### 評価

- 貸出完了時に利用者が 5 段階評価。
- 提供者の稼働率は `last_seen` の履歴から計算（P2 で時系列を保存）。

## P2 インスタンス運用

- 再起動 / 破棄 / ログ閲覧（Docker ログを中継）。
- メトリクス: CPU / RAM / GPU 使用率を 60 秒間隔で保存し、貸出画面にグラフ表示。
- HTTP 公開: テンプレートの 8080 等をサブドメインでプロキシ（要リバースプロキシ設定）。
- 永続ボリューム: 貸出をまたいで保持するボリューム（無料枠の範囲で提供）。

## 運用

- Discord サーバーへの参加必須。LP・ログイン画面・未所属時の案内ページの 3 箇所で案内する。
- 招待リンクは `GPUPOD_DISCORD_INVITE_URL` で設定。未設定時は「運営に確認してください」と表示。
- 利用規約への同意は取得する（無料でも免責・禁止事項は必要）。
