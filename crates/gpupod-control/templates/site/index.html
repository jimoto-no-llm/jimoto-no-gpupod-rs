GPUを提供する場合

空き時間だけの提供で構いません。受付は ON/OFF でき、止めたいときに止められます。電気代・通信費・機材費は提供者の負担で、運営からの支払いはありません。

  • Docker が動く Linux と、対応する GPU が必要です
  • GPU ドライバーとコンテナ実行環境は提供者が用意します
  • 受付 OFF は新規の貸出を止めるだけで、実行中のものは継続します
提供者募集の詳細

提供の前に知っておくこと

貸出中のコンテナは提供者の GPU とメモリを使います。負荷が高い時間帯は受付を OFF にしてください。

承認済みテンプレート以外は起動できません。ホストのファイルを渡す仕組みはありません。

よくある質問

本当に無料ですか？

はい。利用料金はかかりません。運営は課金を行いません。提供者の空き時間を使っているため、稼働時間や性能の保証はありません。

Discord に参加しないと使えませんか？

はい。利用には Discord サーバーへの参加が必須です。参加は無料で、どなたでも可能です。

GPU を持っていなくても使えますか？

使えます。借りるだけなら GPU は不要です。提供に協力する場合は、対応 GPU と Docker が動く Linux マシンが必要です。

作業中に提供PCの電源が落ちたらどうなりますか？

提供PCの都合で実行が終了する場合があります。長い処理はこまめに保存してください。稼働時間の保証はありません。

作業データは残りますか？

返却時に削除されます。提供PC側に作業内容が残り続けることはありません。

提供PCのIPアドレスは公開されますか？

公開しません。接続は中央サーバーの中継を経由し、公開するのは GPU 名・ベンダー・VRAM・提供者の表示名・空き状態だけです。
