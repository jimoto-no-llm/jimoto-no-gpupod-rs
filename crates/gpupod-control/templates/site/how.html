使い方

借りる人・提供する人、どちらも最初は Discord サーバーへの参加から始まります。参加は無料で、どなたでも可能です。

Discord サーバーに参加する

Jimoto GPU Pod は Discord サーバー（ID: {{ ctx.guild_id }}）のメンバーだけが利用できます。

  1. 招待リンクから Discord サーバーに参加する（参加は無料です）
  2. このサイトに戻り「Discord でログイン」を選ぶ
  3. 利用パネルでGPUを選んで借りる、または提供PCを登録する

GPU を借りる

  1. 1

    ログインする

    「Discord でログイン」からアカウントを連携します。

  2. 2

    GPU とテンプレートを選ぶ

    利用パネルの一覧から、いま借りられるGPUを選び、承認済みテンプレートと資源の予約量を指定します。

  3. 3

    SSH で接続する

    貸出画面に表示された接続先とポートへ SSH します。接続には利用者本人の SSH 公開鍵を使います。

接続の例
# 貸出画面に表示されたポートとホストに置き換えてください
ssh -p 19427 pod@gpu.example.org

SSH ユーザーは pod、作業場所は /workspace です。接続先とポートは貸出ごとに発行されます。

作業が終わったら、利用パネルから返却してください。作業データは返却時に削除されます。

接続の仕組み

接続は中央サーバーの中継を経由します。提供PCに公開ポートは不要で、提供PCのIPアドレスや内部IDは利用者に公開されません。

貸出ごとに中継ポートが割り当てられ、SSH は利用者の公開鍵で認証します。パスワード認証は使いません。

中継ポートは 19001〜19999 の範囲から貸出ごとに割り当てられます（運用設定により変わります）。

利用規約を確認する

返却について

利用パネルから返却すると、コンテナと作業データが削除されます。返却を忘れると貸出が続くため、作業後は早めに返却してください。

中断について

提供PCの都合で実行が終了する場合があります。無料運用のため、稼働時間や性能の保証はありません。長い処理はこまめに保存してください。

公開される情報

GPU名・ベンダー・VRAM・提供者の表示名・空き状態だけを公開します。IPアドレスや内部IDは公開しません。

GPU を提供する

提供PCは中央サーバーへ外向きに接続するだけです。公開ポートや固定IPは必要ありません。

  1. 1

    Discord に参加

    コミュニティに参加し、提供の条件を確認します。

  2. 2

    提供PCを登録

    提供PC管理から登録し、トークンをエージェントに設定します。

  3. 3

    環境を確認

    Docker と NVIDIA Container Toolkit が動作していることを確認します。

  4. 4

    受付をON

    空き時間だけ受付をONにします。OFFにすれば貸出は止まります。
